Как работает

Для выполненного заказа конец окна — время завершения заказа, начало — время завершения минус длительность печати из Bambu Studio.

Фактические кВт·ч и стоимость показываются только как post-print статистика и не меняют сохранённую цену или финансовый snapshot заказа.

Без SSH

На umbrelOS URL, entity ID и токен настраиваются полностью из этой страницы. Ручное редактирование Docker Compose не требуется.

Граница доступа

Клиент Home Assistant содержит только HTTP GET. Он читает состояние выбранного сенсора и его историю. Сервисы, состояния, автоматизации и настройки Home Assistant не изменяются.
